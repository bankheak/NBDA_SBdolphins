# Data

This file contains all the raw data for the NBDA_SBdolphins repository

### Descriptions of data

- `cmdstan_saves_sd` and `cmdstan_saves_fg`: Folders containing results of fit_STb boat-based (SD) and fixed-gear (FG) models.
- `ILV_SD_subset.csv` and `ILV_FG_subset.csv`: Dataframe of each individual's individual level variables for boat-based (SD) and fixed-gear (FG) behaviors.
- `SRI_vert_all.RData`: List of mother-calf matrices.
- `data_list_sd.RData` and `data_list_fg.RData`: Dataframe of the event_data, edge_list, ILV_c, ILV_tv and t_weights using import_user_STb for boat-based (SD) and fixed-gear (FG) behaviors.
- `ecol_all.RData`: List of homerange overlaps between each individual for each year.
- `edge_list_sd.RData` and `edge_list_fg.RData`: Dataframe of inter-event period, dyads and horizontal, vertical, and ecological networks for boat-based (SD) and fixed-gear (FG) behaviors.
- `event_data_sd.csv` and `event_data_fg.csv`: Dataframe of acquisition times of target behavior for each individual for boat-based (SD) and fixed-gear (FG) behaviors.
- `model_strong_priors_sd.STAN` and `model_strong_priors_fg.STAN`: STAN files for model with priors and other input data for boat-based (SD) and fixed-gear (FG) behaviors.
- `nxn_sd.RData` and `nxn_fg.RData`: List of association matrices for each inter-event periods for boat-based (SD) and fixed-gear (FG) behaviors.
